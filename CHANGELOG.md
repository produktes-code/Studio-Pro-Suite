# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-06-23

### Added
- **Cinema Generator Pro:** A structured, parameter-driven prompting module for cinematographers to control focal length, lighting styles, camera setups, and atmospheres.
- **Script Writer Pro:** Narrative-to-technical screenplay builder with virtual directors/DOPs (AI Cast & Crew) and persistent character sheets.
- **ZEO 4 Cinema Studio:** Parametric console for video generation and mathematical camera conditioning (Pan, Tilt, Zoom, Roll, Roll 3D).
- **Pollinations AI Integration:** Native support for the Flux image generation model to simulate and preview prompts in real-time.
- **Ecosystem Localizations:** Global support for 7 languages (Spanish, English, German, Russian, Japanese, Ukrainian, and Chinese) in the user interface.
- **Desktop Executables:** Configuration for building native packages (.dmg and .exe) using Electron Builder.
- **Iniciar_StudioPro.command:** Universal script to easily run the React app and start the suite on macOS.
