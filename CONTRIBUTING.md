# Contributing to Studio Pro Suite

Thank you for choosing to contribute to Studio Pro AI Suite! We welcome community contributions to help improve this virtual cinematic prompting workspace.

## Code of Conduct
Please make sure to be respectful and constructive in all community discussions and contributions.

## How to Contribute

### Reporting Bugs
1. Search open issues to see if the bug has already been reported.
2. If it is new, open a new Issue, detailing:
   - Your environment (OS, Node.js version)
   - Steps to reproduce the bug
   - Screen capture or console logs if available

### Suggesting Enhancements
1. Open an Issue with the prefix `[Feature Request]`.
2. Clearly explain the visual control, parameter, or integration you propose and its user benefits.

### Pull Requests
1. Fork the repository and create your branch from `main`.
2. Verify that your code complies with the project style guidelines:
   - Run `npm run build` locally to verify production-ready bundle compilation.
   - Run `npm run lint` if ESLint is configured.
3. Commit your changes with semantic, descriptive messages.
4. Open a Pull Request pointing to the `main` branch.
