## 🎯 Overview
**Studio Pro Suite** is a state-of-the-art parametric prompt generation engine and narrative pre-production layout manager engineered for professional Directors of Photography, cinema directors, and generative AI prompt engineers. It functions as a precise hardware-to-aesthetic compiler that translates abstract cinematic intent into mathematically and physically accurate payloads for modern video and image generation engines (such as Sora, Veo, Runway, Kling AI, and Pollinations AI).

---

## 🛠️ Key Features
*   **Cinema Generator Pro:** Select anamorphic or spherical lenses, real camera bodies (e.g. IMAX, ARRI), lighting setups, and visual styles based on legendary filmmakers.
*   **Script Writer Pro:** Build technical scene breakdowns (Shot Cards) from a logline, managing visual continuity via the built-in character memory.
*   **ZEO 4 Cinema Studio:** A specialized module for animating shots and generating 3D camera trajectories (Pan, Tilt, Zoom, Roll) compiled into precise JSON payloads and CLI commands.
*   **Pollinations AI Integration:** Real-time rendering through the Flux model to preview generated prompts directly within the application.

## ⚙️ Installation and Setup

### Local Development Execution
1. Ensure you have Node.js installed.
2. Open a terminal in the project directory.
3. Run the startup script:
   ```bash
   ./Iniciar_StudioPro.command
   ```
   *(Make sure to grant execution permissions first with `chmod +x Iniciar_StudioPro.command` if necessary)*.
4. The application will automatically open in your default web browser at `http://localhost:5175`.
